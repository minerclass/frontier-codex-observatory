Direct source collection

  • Read the four Vals leaderboard tables and methodology notes.
  • Re-read selected Google, OpenAI, Anthropic, Meta and SpaceXAI launch tables for revision 02.
  • Preserve printed benchmark versions, effort, tools and fallback rules; unknown settings stay empty.
  • Keep distinct benchmark IDs for different publisher setups, including Terminal-Bench 4.0-AA and Composer’s Cursor CLI run.

What the comparison supports

  • All numbers are published results or explicitly derived values. This project did not run the benchmark models.
  • Different company and independent scores are source differences; they do not isolate model performance under identical conditions.
  • The effective Codex model ID was not captured, so compiler intelligence cannot be attributed to a named model.
  • Initial data collection predates the atlas brief. Later handoffs were read before a first Git commit, so this is not a blinded agent comparison.
